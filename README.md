# Student Performance Machine Learning

Applied machine learning coursework for predicting student performance.

The notebook and source CSV were extracted from [ppv10/Projects](https://github.com/ppv10/Projects/tree/main/Applied%20Machine%20Learning%20project). The written report stays in the archive.

The notebook uses a seeded train/test split, training-only model selection, feature selection inside cross-validation, and scaled inputs for the MLP model. It clears saved cell output so results can be reproduced by running the notebook.
